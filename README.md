# Samuel Restrepo — Portfolio

Sitio estático listo para Netlify. No necesita instalación ni proceso de compilación.

## Publicación en Netlify

1. Conecta este repositorio a Netlify.
2. Deja vacíos los campos de comando de compilación y directorio de publicación.
3. Publica desde la rama principal.

## Añadir un proyecto

Edita el arreglo `projects` al inicio de `script.js`:

- `video`: enlace público de YouTube o Vimeo.
- `pdf`: enlace público del brochure, press kit o PDF.
- `card` y `shape`: colores de la tarjeta.

Al tener fotografías reales, pueden reemplazarse los fondos gráficos de las tarjetas con imágenes optimizadas.
